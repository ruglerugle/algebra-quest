第3章 STAGE 6

正多角形の作図

作図できる正 n 角形の判定
🎯 ミッション
1 の5乗根 ζ と t＝ζ＋ζ⁻¹ を使って cos 72°＝(√5−1)/4 を導き、正5角形が作図できることを確かめよう。正7角形では t³＋t²−2t−1＝0 が既約で作図できないこと、正 p 角形（p は素数）が作図できるのは p がフェルマー素数のときだけであることを説明できれば合格。
未達成
ねこ博士
作図できる数の判定法を、正多角形に使ってみよう。紀元前300年ごろのユークリッドの『原論』には、正3角形・正4角形・正5角形・正6角形・正15角形の作図と、辺の数を2倍にする方法が書かれている。でも、そのほかの正多角形は、2000年以上だれも作図できなかった。正7角形はできるのか、正17角形はどうか。今日の道具で、その答えを出すことができる。半径 1 の円に内接する正 n 角形を考えよう。作図できるかどうかは、何が作図できるかで決まるかな？
うさ美
頂点の1つを (1, 0) にとると、となりの頂点は中心角 360°/n の方向にあるので、座標は (cos(360°/n), sin(360°/n)) です。sin は √(1−cos²) で cos から作図できるので、cos(360°/n) が作図できれば、その頂点が作れます。あとは、となりの頂点までの長さをコンパスで次々に写せば、全部の頂点が作れます。正4角形は cos 90°＝0、正6角形は cos 60°＝1/2 なので作図できます。正5角形の cos 72° は、まだ分かりません。
正 n 角形の作図は cos(360°/n) の作図と同じ（図は n＝5）。頂点の1つを (1, 0) にとると、となりの頂点は (cos 72°, sin 72°)。横の座標 cos 72° が作れれば、sin 72°＝√(1−cos²72°) は √ で作れて、この頂点が決まる。あとは辺の長さをコンパスで写していけば残りの頂点も決まる
ねこ博士
そう。cos 72° を求めるのに、複素数を使おう。長さ 1、角度 72° の複素数を ζ（ゼータ）とする。ζ⁵ は何になるかな？
うさ美
複素数の掛け算は角度を足すので、ζ⁵ の角度は 72°×5＝360°、長さは 1 なので、ζ⁵＝1 です。ζ⁵−1＝0 で、ζ⁵−1＝(ζ−1)(ζ⁴＋ζ³＋ζ²＋ζ＋1) と分けられます（右辺を展開すると、真ん中の項が打ち消し合って ζ⁵−1 になります）。ζ≠1 なので、ζ⁴＋ζ³＋ζ²＋ζ＋1＝0 です。
ねこ博士
その通り。ζ は 1 の5乗根と呼ばれる数の1つだ。ここからが工夫のしどころだ。両辺を ζ² で割って、t＝ζ＋ζ⁻¹ という数を使って書き直してごらん。ζ⁻¹ は 1/ζ のことだよ。
うさ美
ζ⁻¹ は長さ 1、角度 −72° の複素数なので、ζ⁻¹＝cos 72°−i sin 72° です。だから t＝ζ＋ζ⁻¹＝2cos 72° で、t は実数です。両辺を ζ² で割ると、ζ²＋ζ＋1＋ζ⁻¹＋ζ⁻²＝0。t²＝ζ²＋2＋ζ⁻² なので ζ²＋ζ⁻²＝t²−2。代入すると (t²−2)＋t＋1＝0、つまり t²＋t−1＝0 です！ 解の公式で t＝(−1±√5)/2。cos 72° は正なので t＝(√5−1)/2、cos 72°＝(√5−1)/4 です。
ζ＝cos 72°＋i sin 72°、ζ⁵＝1、ζ≠1 → ζ⁴＋ζ³＋ζ²＋ζ＋1＝0 ζ² で割る：(ζ²＋ζ⁻²)＋(ζ＋ζ⁻¹)＋1＝0 t＝ζ＋ζ⁻¹＝2cos 72° とおくと t²＝ζ²＋2＋ζ⁻² なので ζ²＋ζ⁻²＝t²−2 (t²−2)＋t＋1＝0 → t²＋t−1＝0 → t＝(√5−1)/2（t＞0 のほう） cos 72°＝(√5−1)/4≒0.309。√5 だけで書けるので次数 2 → 正5角形は作図できる
1 の n 乗根と t＝ζ＋ζ⁻¹。単位円の上の点 ζ, ζ², …（角度 360°/n ずつ）を並べた。ζk と ζ−k（上下に向かい合う点）を足すと、虚部が打ち消し合って実数 2cos(360°×k/n) になる（点線と横軸の交点の2倍）。n＝5 ではこの値が2つで t²＋t−1＝0 の2つの解、n＝7 では3つで3次方程式の解、n＝17 では8つになる
ねこ博士
よく求めたね。cos 72° が分かれば、正5角形を実際に作図できる。いちばん上の頂点を B＝(0, 1) にとって、次の手順で辺の長さを作ろう。半径 1 の円で、横の直径の左端を (−1, 0) とし、O と (−1, 0) の真ん中の点を M＝(−1/2, 0) とする。M を中心に B を通る円をかき、横の直径（を延ばした直線）との右側の交点を N とする。ON と BN の長さを求めてごらん。
うさ美
MB は三平方の定理で √((1/2)²＋1²)＝√5/2 です。N は M から右へ √5/2 進んだ点なので、ON＝−1/2＋√5/2＝(√5−1)/2。さっきの t です！ BN は三平方の定理で BN²＝t²＋1。t²＋t−1＝0 から t²＝1−t なので、BN²＝2−t です。
ねこ博士
そう。では正5角形の1辺はどうかな。B と、そのとなりの 18° の方向の頂点 (cos 18°, sin 18°) との距離を2乗してごらん。
うさ美
cos²18°＋(sin 18°−1)²＝cos²18°＋sin²18°−2 sin 18°＋1＝2−2 sin 18° です。
ねこ博士
sin 18° は cos 72° と同じ値だね。
うさ美
cos 72°＝t/2 なので、2−t。BN² と同じです。BN は正5角形の1辺の長さだということですか？
BN が正5角形の1辺になる理由。左は半径 1 の円。M を中心に B を通る円（点線の弧）が横の直線と交わる点が N で、ON＝t。赤い BN と、B からとなりの頂点 P＝(cos 18°, sin 18°) までの緑の BP の長さを、それぞれ2乗して比べる。右の2つの計算はどちらも 2−t になるので、2本の長さは等しい。途中で使ったのは t²＝1−t（t の方程式）と sin 18°＝cos 72°＝t/2 の2つ
正5角形の作図。「次へ」で1手ずつ進む。赤がいま引いた線や円。ON の長さが t＝2cos 72°＝(√5−1)/2 で、BN が1辺の長さになる。B を中心に半径 BN の円をかけば両どなりの頂点が、そこからさらに同じ半径の円をかけば残りの頂点が決まる
ねこ博士
その通り。では正7角形はどうかな。ζ を長さ 1、角度 360°/7 の複素数として、同じ方法で t＝ζ＋ζ⁻¹＝2cos(360°/7) の方程式を作ってごらん。
うさ美
ζ⁷＝1、ζ≠1 なので 1＋ζ＋ζ²＋…＋ζ⁶＝0。ζ³ で割ると (ζ³＋ζ⁻³)＋(ζ²＋ζ⁻²)＋(ζ＋ζ⁻¹)＋1＝0。ζ²＋ζ⁻²＝t²−2 で、t³＝ζ³＋3ζ＋3ζ⁻¹＋ζ⁻³ なので ζ³＋ζ⁻³＝t³−3t。代入すると (t³−3t)＋(t²−2)＋t＋1＝0、つまり t³＋t²−2t−1＝0。有理数の根の候補は ±1 で、1＋1−2−1＝−1、−1＋1＋2−1＝1 なので、どちらも根ではありません。既約な3次式なので t の次数は 3 です。正7角形は作図できません。
ζ＝cos(360°/7)＋i sin(360°/7)、1＋ζ＋ζ²＋…＋ζ⁶＝0 ζ³ で割る：(ζ³＋ζ⁻³)＋(ζ²＋ζ⁻²)＋(ζ＋ζ⁻¹)＋1＝0 t＝ζ＋ζ⁻¹：ζ²＋ζ⁻²＝t²−2、ζ³＋ζ⁻³＝t³−3t（t³ を展開して 3t を引く） t³＋t²−2t−1＝0。候補 ±1 は根でない → 既約 → 2cos(360°/7) の次数は 3 → 正7角形は作図できない
ねこ博士
その通り。この方法は、辺の数が素数 p のとき、いつでも使える。ζ は 1＋x＋x²＋…＋xᵖ⁻¹＝0 の根で、この (p−1) 次式は既約だと証明できる（第4章で出てくるアイゼンシュタインの判定法を使う）。だから ζ の次数は p−1。t＝ζ＋ζ⁻¹ を加えた体から ζ までは、ζ が2次方程式 x²−tx＋1＝0 の根なので、次数は 2 だ。すると t の次数はいくつかな？
うさ美
次数の積の法則で、p−1＝[ℚ(ζ)：ℚ]＝[ℚ(ζ)：ℚ(t)]×[ℚ(t)：ℚ]＝2×[ℚ(t)：ℚ] なので、t の次数は (p−1)/2 です。p＝5 なら 2、p＝7 なら 3 で、さっきの計算と合います。作図できるには (p−1)/2 が 2 の累乗、つまり p−1 が 2 の累乗でなければいけません。p＝2k＋1 の形です。k＝1, 2, 3, 4, 5, 6, 7, 8 で 3, 5, 9, 17, 33, 65, 129, 257 で、素数なのは 3, 5, 17, 257 です。正17角形は作図できるかもしれません！
正 p 角形（p は素数）の塔。左：ζ の次数は p−1 で、t＝ζ＋ζ⁻¹ から ζ までは次数 2。だから t の次数は (p−1)/2 で、これが 2 の累乗であるためには p＝2ᵏ＋1 の形が必要。右：k＝1〜8 で 2ᵏ＋1 が素数になるのは 3, 5, 17, 257 の4つ（緑）
ねこ博士
そう。2k＋1 が素数になるのは、k が 2 の累乗のときだけなんだ。k が奇数の約数をもつと、たとえば 2⁶＋1＝(2²)³＋1 が 2²＋1＝5 で割り切れて 65＝5×13 となるように、必ず分けられてしまうからね。こうしてできる 22m＋1 の形の素数をフェルマー素数という。3, 5, 17, 257, 65537 の5つだ。フェルマーは1640年ごろ、この形の数はすべて素数だと予想したけれど、1732年にオイラーが 2³²＋1＝4294967297＝641×6700417 と分けられることを見つけた。それ以降、6つ目のフェルマー素数は見つかっていない。
フェルマー数 2^(2ᵐ)＋1。m＝0〜4 の 3, 5, 17, 257, 65537 は素数で、これがフェルマー素数。m＝5 の 4294967297 は 641 で割り切れることをオイラーが見つけた。それより先で素数になるものは、いまも見つかっていない
うさ美
正17角形を作図するには、2cos(360°/17) の次数が (17−1)/2＝8＝2³ で、2 の累乗にはなっています。でも、次数が 2 の累乗でも作図できるとは限らない、という話でした。本当に作図できるんですか？
ねこ博士
いい質問だね。それを実際に示したのが、ガウスだ。1796年3月、19歳の誕生日の1か月前のガウスは、cos(360°/17) を √ だけで書く方法を見つけた。2次方程式を4回解くと届くんだ。ガウスはこの発見をきっかけに数学者になる決心をしたと言われ、自分の墓に正17角形を刻んでほしいと望んだという話も伝わっている。式はこうなる。
16cos(360°/17)
＝−1＋√17＋√(34−2√17)
　＋2√(17＋3√17−√(34−2√17)−2√(34＋2√17)) 数値で確かめると、どちらも cos(360°/17)≒0.93247 √ が4重に重なっている → ℚ ⊂ K₁ ⊂ K₂ ⊂ K₃ ⊂ K₄ と次数 2 の段を4つ重ねた体に入る（ζ の次数 16＝2⁴）
うさ美
√ の中にさらに √ が入っていて、4段の体の塔になっているんですね。正5角形のときは √5 の1段でした。正3角形・正5角形・正17角形が作図できて、正7角形・正11角形・正13角形はできない。辺の数が素数でないときはどうなるんですか？
正17角形の体の塔。ガウスの式の √ を内側から順に加えていくと、ℚ → ℚ(√17) → √(34−2√17) を加える → もう1つ √ を加える、と次数 2 の段が3つ積み上がり、cos(360°/17) は3段目（ℚ 上の次数 8＝2³）に入る。ζ 自身はさらにもう1段上（次数 16＝2⁴）。どの段も次数 2 なので、作図できる
ねこ博士
それも、ガウスが答えを書いている。正 n 角形が作図できるのは、n が「2 の累乗 × 異なるフェルマー素数の積」の形のときで、そのときに限る。ガウスはこれが十分であることを示し、必要であることは1837年にヴァンツェルが証明した。第1章で学んだ φ(n)（1 から n までのうち n と互いに素な数の個数）を使うと、「φ(n) が 2 の累乗のとき、そのときに限る」とも言いかえられる。正 n 角形の頂点 ζ の次数が、ちょうど φ(n) になるからだ。正9角形で確かめてごらん。
うさ美
9＝3×3 で、フェルマー素数 3 を2回使っているので、作図できません。φ(9) は 1〜9 のうち 3 の倍数でない数 1, 2, 4, 5, 7, 8 の6個で、2 の累乗ではありません。正9角形の中心角は 40° です。もし 40° が作図できたら、それを二等分して 20° が作れてしまうので、前のステージの結果とも合っています。正15角形は 3×5 で φ(15)＝8 なので作図できて、ユークリッドの『原論』と合います。
どの正 n 角形が作図できるか。スライダーで n を選ぶと、正 n 角形と φ(n)（1 から n までのうち n と互いに素な数の個数）を表示する。φ(n) が 2 の累乗（1, 2, 4, 8, 16, …）なら作図できる（緑）、そうでなければできない（赤）。下の表は n＝3〜40 の一覧。作図できるのは、n が 2 の累乗とフェルマー素数 3, 5, 17, 257, 65537（それぞれ1回まで）の積になっているとき
ねこ博士
その通り。2000年も止まっていた正多角形の作図を、ガウスは「体の次数」の考え方で一気に解決した。ここまでで、作図の謎はすべて体の言葉で説明できた。次のステージでは、体のもう1つの顔を見よう。有限個の数でできた体だ。
うさ美
mod p の世界は、p 個の数しかないのに体でした。有限個の数の体が、作図とは別のところで役に立つんですか？
ねこ博士
そう。スマートフォンで QR コードを読むとき、汚れや欠けがあっても正しく読めるのは、有限の体のおかげなんだ。最後のステージで、その仕組みを確かめよう。
【このステージの成果】 正 n 角形の作図は cos(360°/n) の作図と同じ。ζ＝cos(360°/n)＋i sin(360°/n) は ζⁿ＝1 をみたす（1 の n 乗根） 正5角形：t＝ζ＋ζ⁻¹＝2cos 72° は t²＋t−1＝0 → cos 72°＝(√5−1)/4（次数 2）→ 作図できる。BN²＝t²＋1＝2−t が1辺の2乗 正7角形：t³＋t²−2t−1＝0 は既約 → 次数 3 → 作図できない 正 p 角形（p は素数）：t の次数は (p−1)/2 → p はフェルマー素数 3, 5, 17, 257, 65537 でなければならない ガウス（1796年）：正17角形は √ を4重に使って作図できる。正 n 角形が作図できる ⇔ φ(n) が 2 の累乗

確認クイズ

Q1. 1 の5乗根 ζ について、t＝ζ＋ζ⁻¹ がみたす方程式は？

正解！ ζ⁴＋ζ³＋ζ²＋ζ＋1＝0 を ζ² で割り、ζ²＋ζ⁻²＝t²−2 を使うと (t²−2)＋t＋1＝0。t³＋t²−2t−1＝0 は正7角形のほう。

Q2. 正7角形が定規とコンパスで作図できない理由は？

正解！ 候補 ±1 を入れると −1 と 1 で、有理数の根がない。3次式なので既約で、次数 3 は 2 の累乗でない。正5角形の 5 も奇数で、360÷5 も割り切れるが、それは理由にならない（正17角形は 360 が割り切れないのに作図できる）。

Q3. 次のうち、定規とコンパスで作図できる正多角形は？

正解！ 17 はフェルマー素数（2⁴＋1）で φ(17)＝16＝2⁴。正9角形は φ(9)＝6、正11角形は φ(11)＝10 で、どちらも 2 の累乗でない。
